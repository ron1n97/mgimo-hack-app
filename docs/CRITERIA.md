# Критерии оценки — Вайб-кодинг (канон)

Источник: бриф ЛК MGIMO×AI + [Регламент §7](https://challenge.mgimo.ai/rules) (ред. 22.10.2026).  
**Правило проекта:** любое решение в коде/дизайне/PDF должно явно бить в ≥1 критерий. Если не бьёт — не делаем.

## Формула

- 4 критерия × до **10** баллов каждый (макс. 40 у одного эксперта).
- Каждую работу оценивают **все** эксперты.
- Итоговый балл = **среднее арифметическое** баллов экспертов.
- Ранжирование отдельно по номинации → 1 / 2 / 3 место (150 / 100 / 75 тыс. ₽).

## 1. Проработанность идеи (до 10)

Насколько глубоко продуман кабинет:

- понятна **проблема студентов**, которую он решает;
- сценарии вокруг **реальных задач**;
- **обязательное ядро** реализовано полностью;
- повышают оценку **сильные и смелые идеи**, которые меняют опыт общения студента с деканатом.

**Как закрываем мы:**
- **R-SURVEY** — опросник в студенческую группу (`docs/research/survey-draft.md`)
- **R-FG** — фокус-группа студентов (`docs/research/`)
- `docs/PAINS.md` обновлять фактами → UI/демо/PDF · hero-path · narrative seeds

## 2. Масштаб использования нейротехнологий (до 10)

Насколько широко и осмысленно ИИ использован в разработке:

- продуманность процесса;
- качество промптов и постановки задач ассистентам/субагентам;
- проработка документов/файлов для ИИ-агентов;
- работа с ошибками ИИ;
- ИИ для дизайна и контента;
- полнота и наглядность **описания процесса** (PDF сдачи).

**Как закрываем мы:** работа **только через ИИ-ассистентов** · `docs/process-log/` с D1 (в т.ч. скилл **`/idea`** на этапе стратегии) · `CLAUDE.md`/`SCOPE` как инструкции агентам · in-product AI1–AI3 · честные фейлы в PDF.

## 3. Имплементация (до 10)

- прототип открывается и работает;
- основные сценарии без ошибок, данные сохраняются;
- полноценно на **телефоне**;
- безопасность: только свои данные; пароли/ключи защищены; только вымышленные данные;
- тестовые аккаунты работают;
- иные требования брифа (дисклеймер, без лого вуза, RU без VPN…).

**Как закрываем мы:** **sign-off Романа** · E2E happy-path · IDOR в демо · RU host+mirror · R5 checklist. Агент собирает — owner подтверждает «можно жюри».

## 4. Качество (до 10)

- современный цельный визуальный стиль;
- понятная навигация, нужное быстро;
- пустые состояния, ошибки, загрузка;
- быстрый и доступный интерфейс;
- хочется пользоваться каждый день.

**Как закрываем мы:** дисциплина `CLAUDE.md` (TDD/ADR/pre-commit) · mobile-first · status theater · empty/error/loading · не purple-SaaS.
