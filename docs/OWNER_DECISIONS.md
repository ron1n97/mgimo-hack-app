# Решения Романа (простым языком)

Обновлено: 2026-11-08

| Вопрос | Решение |
|--------|---------|
| Дедлайн конкурса | Не режем мечту. Делаем **надолго**. К 22.11 всё равно стараемся сдать рабочее — полнота наше преимущество. |
| Что делаем | **Всё:** сайт, мобильное приложение, телеграм-бот, кабинет не только студента. |
| Кто платит за сервер | **Роман.** Токен/доступ даст отдельно (не светить в git). |
| Нейросеть | Ключ **Z Code**, подключаем **как OpenRouter** (стандартный OpenAI-совместимый клиент). |
| Расписание | Тянем с открытого API МГИМО (RUZ), все группы. |
| База / деплой | Нормальная архитектура: Postgres, Docker, несколько контейнеров, без ручной боли и без SQLite как основы. |

Секреты (токен хостинга, Z Code): только `.env` / менеджер секретов. В чат — лучше ссылкой «положи в файл», не коммитить.
