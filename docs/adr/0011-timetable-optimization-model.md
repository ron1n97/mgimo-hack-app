# 0011. Модель оптимизации расписания (CP-SAT sidecar)

## Статус
Предложено

## Дата
2026-11-11

## Контекст
MVP кабинета преподавателя ([0007](./0007-teacher-lesson-assignments.md)) сознательно без солвера. Параллельно нужна формальная постановка авторасписания: группы/подгруппы/языковые потоки, аудитории с признаками, ставки, учебный план, календари.

## Решение
1. Каноническая постановка и математическая модель — в research-доке: [`docs/research/timetable-optimization-model.md`](../research/timetable-optimization-model.md).
2. Решатель: Google OR-Tools **CP-SAT** в отдельном sidecar/worker (не в request-path API).
3. Переменные v1: предперечисленные activity-instances $a \in A$ → назначение $(t,r,p)$; покрытие плана — hard при фиксированном $|A|$.
4. Мягкие цели — линейная скаляризация с конфигурируемыми $\lambda_k$ (без захардкоженных весов в модели).

## Последствия
- Нет кода солвера в этом ADR; только указатель на модель.
- Нужны ответы на open questions из research-дока (вложенность языковых групп, типы занятий, грид слотов, multi-teacher) до реализации.
- Согласуется с 0007: продуктовый MVP без солвера; оптимизация — отдельный этап.
