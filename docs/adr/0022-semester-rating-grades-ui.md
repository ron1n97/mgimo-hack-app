# 0022. Semester rating UI for Успеваемость

## Статус
Принято

## Дата
2026-11-23

## Контекст
Плоский список «оценка / долг» на `/grades` выглядел бедно рядом с привычным ЛК (рейтинг за семестр, Б1/Б2/Б3, вкладки). Для демо жюри нужен густой, честный учебный срез без копирования лого вуза и без боевых ПДн.

## Решение
1. Чистая модель `rating-model.ts`: парсинг 5-балльных / 100-балльных / «зачет» / «неявка», ECTS-метка, взвешенный итог `0.4·Б1 + 0.5·Б2 + 0.1·Б3 + 0.05·надбавка` (потолок 100).
2. `GET /grades/me/overview` отдаёт `rating.bySemester` + disclaimer.
3. Web `/grades`: селектор семестра, карточки рейтинга, вкладки (экзамены / зачёты / срезы / соц. характеристики / по дисциплине), модалка «Как считается».
4. Сиды: у Спокойного/Орлова/Романа — плотный «весенний» пакет; у Рисковой — долги + более тонкий соседний семестр.

## Последствия
- Не офиц. ЛК: срезы и соц. баллы — детерминированная демо-производная, не импорт из вуза.
- После tip-cut нужен `seed:extras`, иначе live останется на старых коротких пакетах оценок.
