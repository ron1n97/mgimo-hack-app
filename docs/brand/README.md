## Чем брендбук отличается от палитры

- **Логобук** — только знак  
- **Гайдлайн** — лого + цвет + шрифт + примеры  
- **Брендбук** — платформа, тон, гайдлайн, носители, запреты  

В PDF по каждому из 4: платформа · лого · цвет · тип · ToV · UI · носители · don’t.

## Четыре концепции

1. **Кабинет** (Editorial Copper) — спокойный академический кабинет · *рекомендация для продукта*  
2. **Кампус** (Campus System) — системный student-app тон  
3. **Пульс** (Campus Pulse) — живой дайджест/клубы  
4. **Протокол** (Protocol A11y) — зал/проектор/доказуемость  

Стандарты-каркас: Apple HIG + Material Design 3 roles.
