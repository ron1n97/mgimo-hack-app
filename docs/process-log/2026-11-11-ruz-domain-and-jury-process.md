## Честные фейлы / риски

1. **Данные РУЗ конфликтны** (~80 пересечений/нед, `!Не определена`) — нельзя калибровать feasibility по «как сейчас в проде».
2. **Wish нет в API** — мягкий календарь преподавателя откладывается до опроса кафедр; иначе только hard Avail у почасовиков.
3. **PE / физкультура** — разметка в РУЗ неясна коллеге; в v1 не закрепляем kind.
4. **Q9** (shared rooms / внешние приоритеты) остаётся размытым без формулировки заказчика.
5. Солвер по-прежнему **не** в MVP продукта (ADR 0010) — документ для постановки/жюри/будущего sidecar.
