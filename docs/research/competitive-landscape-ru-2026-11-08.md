# Конкурентный ландшафт РФ — ЛК / цифровой деканат / расписание

**Дата доступа:** 2026-11-08  
**Назначение:** вход в идеальный продукт Деканат+.  
Связано: `ideal-product-backlog.md`, `student-experience-platforms-benchmark-2026-11-08.md`.

## Короткий вывод

1. У сильных вузов **нет одного приложения** — есть зоопарк (расписание / оценки / справки / бот).  
2. Лучший «единый кабинет» в РФ по глубине — **my.itmo**.  
3. Лучшие заявки/справки по сервису — **НИУ ВШЭ** (быстрые e-справки).  
4. Лучший UX расписания у **агрегаторов** (Дневач, Кампус) и ботов — не у официальных ЛК.  
5. **In-product ИИ у студентов почти нигде нет** — пустое поле для нашего преимущества.  
6. МГИМО: `lk` + `ruz` + app SoftSnow + **MGIMO Life bot** — уже экосистема, но фрагмент.

## Разборы (сжато)

### МГИМО
- URL: https://lk.mgimo.ru/login · https://ruz.mgimo.ru/ · https://smc.mgimo.ru/projects/telegram_bot · Play `ru.mgimo.univeronline`
- Сила: мультиповерхность, Life-bot (свободные аудитории, столовая, FAQ, обращения).
- Слабость: фрагментация; AI нет; официальный feature-маркетинг тонкий.

### my.itmo (ориентир «единый мир»)
- https://my.itmo.ru · https://news.itmo.ru/ru/news/13457/ · App Store my.itmo
- ~100 микросервисов: расписание, зачётка, заявки/справки, очереди, пропуск QR, спорт, еда…
- Боль: отзывы ~3.7 — тёмная тема, прошлые дни расписания, сортировка оценок.

### ВШЭ
- https://lk.hse.ru · https://studentcentre.hse.ru · HSE App X
- Сила: сервисный центр, e-справки, push смен расписания.
- Слабость: зоопарк ЕЛК/LMS/RUZ/App; RUZ UI «во внутренней сети».

### Modeus / 1С / Галактика
- Modeus = ИОТ и конфликты расписания (не «деканат справок»).
- 1С = типовой портал вуза, UX зависит от внедрения.
- Галактика РУЗ = движок расписания + tenant REST; МГИМО в клиентах.

### Агрегаторы
- Дневач https://dnevuch.ru — offline, таймер пары, много вузов (в т.ч. МГИМО).
- Кампус https://campusapp.ru — отзывы преподов, виджеты, масштаб; монетизация/реклама в отзывах.
- Берут открытые источники вузов, не «магический API всех вузов».
