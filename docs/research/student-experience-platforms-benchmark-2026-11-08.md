# Student Experience Platforms — Feature Benchmark

**Access date:** 2026-11-08  
**Purpose:** International / best-in-class feature benchmarking for an ideal digital dean’s office (student + staff), beyond basic LMS.  
**Method:** Official product pages, vendor docs, App Store / Play listings, and institution help pages. Consumer UX and “Notion stack” sections include labeled hypotheses where evidence is product-design literature rather than university-app feature lists.

---

## 1. Feature taxonomy

Modern students expect a **life OS for campus**, not only courseware. Features below are grouped into domains used for benchmarking.

### Academics
| Capability | What “good” looks like |
|---|---|
| Course hub | Syllabus, modules, files, quizzes, discussions in one place |
| Grades & feedback | Live grades, rubrics, annotations, “what-if” projections |
| Calendar / timeline | Cross-course deadlines, local + push reminders |
| Progress / completion | Degree audit, competencies, badges, learning plans |
| Registration & records | Schedule build, waitlists, transcripts, holds |
| Advising | Academic progress view, guided program exploration |
| Offline study | Download courses/files; sync submissions later |
| Study aids | Notes, highlights, flashcards, practice quizzes |

### Campus ops
| Capability | What “good” looks like |
|---|---|
| Single hub / SSO | One dashboard over SIS + LMS + services |
| Self-service requests | Letters, status docs, forms without email ping-pong |
| Holds & action items | Clear blockers + next step |
| Journey paths | Orientation, registration, aid — guided step lists |
| Profile & privacy | Contact info, pronunciation, accommodations, privacy settings |
| Campus utilities | Maps, orgs, helpdesk deep-links (often card/portal) |

### Money
| Capability | What “good” looks like |
|---|---|
| Student account | Balance, due now, statements, refunds |
| Payments & plans | Pay, enroll in payment plan, payment elections |
| Financial aid | Awards accept/decline, estimated costs, award year view |
| Tax / compliance docs | e.g. 1098-T consent & view (US-centric examples) |

### Career
| Capability | What “good” looks like |
|---|---|
| Skills / career LMS tracks | Skill-based / lifelong learning pathways |
| Role-play / interview practice | Scenario AI for workplace readiness |
| Application tracking | Status of internships/jobs (often DIY via Notion) |
| Portfolio / evidence | Showcase work, competencies |

### Wellbeing
| Capability | What “good” looks like |
|---|---|
| Resource discovery | Central “assist” hub for campus + partner services |
| Accessibility formats | Audio, ePub, OCR, Immersive Reader, braille, etc. |
| Accommodations | Request / track reasonable adjustments |
| Risk-aware staff view | Staff 360 for support (privacy-gated) — Ellucian NTU pattern |
| Habit / balance tools | Usually **outside** official apps (Notion habit trackers) |

### AI
| Capability | What “good” looks like |
|---|---|
| Course-grounded study | Summaries, quizzes, flashcards from *my* materials |
| Socratic / coach modes | Guides thinking; does not dump answers |
| Instructor-authored AI activities | Persona conversations + reflection + oversight |
| Admin / instructor agents | Content design, feedback drafts, data Q&A |
| Transparent AI | Opt-in, provider disclosure, bias flagging |

### Comms
| Capability | What “good” looks like |
|---|---|
| Activity stream | One feed: grades, announcements, content drops |
| Messaging | Course inbox / peer messages |
| Push / SMS / email | Preference-controlled, high-salience only |
| Widgets | Home-screen deadlines / grades without opening app |
| Announcements targeting | Role- and person-targeted notices |

## 3. Gaps: university apps vs consumer apps

| Gap | LMS/SIS reality | Consumer bar | Why it matters |
|---|---|---|---|
| **Fragmentation** | LMS ≠ SIS ≠ mail ≠ career ≠ tickets | One app owns the job-to-be-done | Students maintain Notion + 5 portals |
| **Actionability** | Many screens are read-only status | Tap → pay / register / generate letter | Ellucian/Workday win when cards *do* work |
| **Time-to-clarity** | Holds without explanation | “Blocked because X — do Y by date” | Reduces anxiety and support load |
| **Cross-course planning** | Per-course To-Do only | Unified week planner (Notion/Calendar) | Exam weeks need whole-life view |
| **Motivation UX** | Deadlines as threats | Streaks, paths, soft recovery (**hypothesis**) | Engagement without gamifying grades poorly |
| **Notification craft** | All-or-nothing email | Personalized, stop-if-ignored pushes | Trust in the app channel |
| **AI placement** | Chat bolted on FAQ | Course-grounded study + Socratic modes | Students already use ChatGPT off-platform |
| **Staff 360** | Staff hunt SharePoint/Banner | Role-gated student timeline | Dean’s office speed + wellbeing |
| **Offline** | Spotty | Moodle/Canvas download norms | Commute / weak campus Wi-Fi |
| **Accessibility as default** | PDF dump | Ally-like alt formats | Equity + mobile reading |
| **Career continuity** | Separate career portal | In-flow skills, role-play, job tracker | Retention & employability narrative |
| **Delight / polish** | Portal aesthetic 2012 | Native widgets, dark mode, instant feedback | Expectation set by banking/travel apps |

## 4. Inspiration list — ideal digital dean’s office (student + staff)

Prioritized for a long-horizon “цифровой деканат” that is **more than LMS**.

### Student surface
1. **Unified Today hub** — deadlines (LMS) + registration holds (SIS) + payments due + ticket replies in one activity stream (Canvas stream + Workday action items + Ellucian cards).
2. **Guided journeys** — orientation, registration, scholarship/aid, dorm, graduation (Workday journeys).
3. **Request factory** — generate/submit certificates, transcripts, academic letters in 1–2 taps (NTU Ellucian letter card).
4. **Finance clarity** — balance, due dates, pay/plan, aid status without jargon (Workday Finance Hub).
5. **Academic truth** — live schedule, grades, degree progress, waitlist push-to-register (Workday mobile records).
6. **Study layer** — notes/highlights + AI summarize/quiz/flashcards grounded in *my* courses (Canvas Notebook + IgniteAI / Gemini / MS Study and Learn).
7. **Coach, don’t cheat** — Socratic / scaffolded AI with reflection & oversight patterns (Blackboard AI Conversation; Khanmigo; MS Study and Learn).
8. **Assist hub** — wellbeing, disability, counseling, career, IT — discoverable like Blackboard Assist + Ally formats.
9. **Comms people actually enable** — preference center; SMS for must-do; widgets for deadlines (Workday SMS + Canvas widgets).
10. **Life beyond classes** — lightweight hooks for clubs/events/career tracker so Notion is optional, not required (**hypothesis** from Notion Education demand).

### Staff / dean’s office surface
1. **Student 360** — one search: academics, requests, adjustments, recent messages (NTU Ellucian Experience staff model).
2. **Queue & SLA** — request inbox with statuses students can already see (closes “where is my справка?”).
3. **Journey analytics** — who stalled on registration/aid steps (Workday engagement overviews).
4. **Policy-aware automation** — templates for letters/holds with audit trail (Experience cards + workflow).
5. **Early-alert collaboration** — role-gated notes across advisor / support / faculty (Workday notes + NTU support views).
6. **AI for staff** — draft replies, summarize case history, suggest next step — human approve (pattern from LMS instructor AI + Illuminate-style data Q&A; keep transparent/opt-in).
7. **Parity mobile** — staff triage on phone for peak periods (registration week).

### Explicit non-goals for an ideal dean’s office (steal LMS, don’t rebuild)
- Full SpeedGrader / quiz engine → integrate LMS.
- Replacing consumer Notion creativity → provide APIs/export and “good enough” planner.
- Dark-pattern gamification of grades → if streaks exist, attach to **healthy habits / task completion**, not GPA theater (**hypothesis**).
