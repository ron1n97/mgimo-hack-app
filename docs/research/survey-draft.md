# Черновик опросника (R-SURVEY) — кинуть в группу

Короткий, мобильный, ≤3 мин. Шкала 1–5: «насколько бесит / мешает».

1. Учёба размазана по разным сайтам/чатам (расписание, оценки, справки, новости).
2. С телефона пользоваться официальными сервисами неудобно.
3. Статус справки/заявления непонятен после подачи.
4. О переносе пары узнаю поздно.
5. Не понимаю «как у меня дела» до сессии.
6. Дедлайны и объявления деканата тонут в чатах/почте.
7. Что важнее всего в одном кабинете? (множественный выбор: расписание / оценки / справки / уведомления / ИИ-помощник / другое)
8. Открытый: «одна ситуация за месяц, когда бесил деканат/ЛК» (текст)

В конце: курс/факультет (опционально), без ФИО.

Инструмент: Яндекс Формы / Google Form — что откроется из РФ без танцев.
