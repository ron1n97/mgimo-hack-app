# Strategy — Comms / сдача жюри

## Получатель

Эксперты MGIMO×AI (маркетинг / ИИ / продукт по публичному составу лендинга) + орг. проверка брифа. Язык: русский.

## Сообщения (3)

1. **Проблема:** учёба студента МГИМО размазана по RUZ / ЛК / чатам / очереди справок — мы собрали **один** сценарий.  
2. **Как сделано:** продукт написан ИИ-ассистентами; процесс воспроизводим (PDF с промптами, фейлами, скринами).  
3. **Доказательство доверия:** два аккаунта, чужие данные не открыть; это **концепт конкурса**, не офиц. сервис.

Запрещённые месседжи: «заменим lk.mgimo.ru»; «настоящие студенты внутри»; «AGI-деканат».

## Артефакты сдачи

| Артефакт | Зачем | Стандарт качества |
|----------|-------|-------------------|
| URL + 2 логина | кр.3 | Открывается из РФ без VPN; happy-path <5 мин |
| Репо/архив | воспроизводимость | README: стек, env example без секретов, как поднять |
| **PDF процесса** | кр.2 | Главы: проблема → ИИ-стек → промпты по этапам → скрины удач/фейлов → security простыми словами → что руками |
| Видео ≤5 мин | кр.1/4 | Телефон: логин A → расписание → оценки → заявка → статус → логин B (изоляция) |
| Коммент в ЛК | вход | Ссылка, аккаунты, 1 абзац «зачем эти разделы» |

## Демо-скрипт жюри (порядок экранов)

1. Дисклеймер на сплэше.  
2. Логин **student A** (risk).  
3. Сегодня/неделя + заметный перенос (если есть в данных).  
4. «Как у меня дела» — красная зона.  
5. Заявка справки → таймлайн статуса.  
6. Уведомление о дедлайне/статусе.  
7. Logout → **student B** — другие оценки/заявки; попытка URL заявки A → deny.  
8. (Опц.) показать кусок PDF/репо с промптом.

## Тон визуала

Не purple-SaaS / не копия бренда МГИМО. Собственный знак «отклик идеи», спокойная академическая атмосфера, mobile-first. Пустые состояния и ошибки — обязательны (кр.4).

## PDF — оглавление (фиксировать)

1. Проблема и инсайты (если будут опросы — цитаты; иначе честно: деск-ресёрч + бриф).  
2. Почему эти разделы и hero-path.  
3. Таблица ИИ-инструментов (Cursor, …) — роль каждого.  
4. Хронология: идея → IA → схема → UI → harden.  
5. Ключевые промпты (до/после / что сломалось).  
6. Скриншоты.  
7. Auth, данные, изоляция — простыми словами.  
8. Что сделано руками (проверка, хостинг, тексты, QA).
